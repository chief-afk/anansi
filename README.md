# Anansi

A free, open-source Android reader for web novels, built to host the source
ecosystems of other apps. Anansi the spider owns all the stories; this app aims
to do the same: one library, many source ecosystems, user-added repositories.

Planned: Kotlin + Jetpack Compose, embedded JS source runtime (LNReader v3 and
v1-era plugins first, Legado book sources later), and a first-class audio reader
built on the platform text-to-speech engine.

Posture: MIT licensed, no ads, no analytics, no monetization, no bundled sources.
Sources come from user-added repository URLs only. Distributed via GitHub Releases.

Status: in design. No usable build yet.
